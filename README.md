# Galactic Command Center

## Overview

**Galactic Command Center** is a Windows Forms application developed as a group project to demonstrate core C# programming concepts. The application simulates a simple spaceship control panel where users can trigger system alerts, upgrade components, calculate weapon damage, and manage cargo events.

This project was built to fulfill the requirements of the class activity, focusing on the following key concepts:

- **Custom Delegates** (including Multicast)
- **Interface vs Delegate**
- **Events**
- **Custom Event Accessors**

The program provides a clear visual interface with buttons that trigger each concept, while all outputs are displayed in a real-time Command Log.

## Features

- Send system alerts using a custom delegate
- Demonstrate multicast delegates
- Upgrade ship components using an interface
- Calculate weapon damage using a delegate
- Handle cargo arrival using events
- Implement custom event accessors with security checks

## How to Run

1. Open the solution file (`.sln`) in Visual Studio.
2. Press **F5** or click **Start** to run the application.
3. Use the buttons on the form to test each feature.
4. Observe the results in the Command Log.
